# 簿記3級 Answer Sheet

日商簿記3級の学習用 Web アプリ（HTML 1ファイル・サーバー不要）。

公開URL: https://takatama-ts.github.io/boki3-training/

## 機能

- **大問2**：汎用表 / 仕訳入力 / 勘定記入 / 短答・空欄入力の4形式で回答を入力
- **大問3**：財務諸表・精算表用の表（勘定科目｜借方｜貸方）
- **AI採点用にコピー**：入力内容を Markdown 表形式でクリップボードにコピー（ChatGPT等に貼って採点してもらう用）
- **トレーニング**：問題JSONをインポートし、表の一部をランダムに空欄化して穴埋め練習・自動採点
  - 「JSONテンプレート」から AI 依頼プロンプトをコピーして、問題を生成させることも可能

入力内容は localStorage に自動保存されます（ブラウザ内のみ。サーバー送信なし）。

## ローカルで開く

`index.html` をブラウザで開くだけで動作します（ビルド不要・外部ライブラリなし）。

## 構成

- `index.html` … アプリ本体（唯一のプロダクションファイル、約1,600行）
- `.nojekyll` … GitHub Pages で Jekyll ビルドを無効化し、ファイルをそのまま配信するためのマーカー
